🤖 Wildberries Parser + Telegram Bot
Этот проект поможет вам парсить товары с Wildberries и получать результаты через Telegram-бота . Все просто и удобно! ✨

📋 Что умеет этот проект?
Парсинг товаров :
🔍 Ищет товары по вашему запросу на Wildberries.
📊 Собирает данные: название, цену, рейтинг и ссылку на товар.
Сохранение в Excel :
📂 Создает красивый Excel-файл с результатами.
Telegram-бот :
💬 Принимает запросы от пользователя.
📥 Отправляет результаты в виде Excel-файла.
🛠 Установка
1. Клонируйте репозиторий
git clone https://github.com/yourusername/wildberries-parser-bot.git
cd wildberries-parser-bot
2. Установите зависимости
pip install -r requirements.txt
3. Настройте .env
Создайте файл .env и добавьте туда токен вашего бота:
API_TOKEN=your_telegram_bot_token_here
▶️ Как использовать?
1. Запустите бота
python bot.py
2. Начните общение с ботом
Откройте Telegram и найдите своего бота.
Используйте команды:
/start — начать работу.
/parse — запустить парсинг товаров.
/help — получить список команд.
